## 📌 Описание проекта

Этот pet-проект представляет собой **RAG-систему (Retrieval-Augmented Generation) с доступом в интернет**, предназначенную для работы в качестве интеллектуального онлайн-консультанта в интернет-магазине. Система способна искать актуальную информацию в интернете, обрабатывать её и генерировать точные ответы на вопросы пользователей на основе найденных данных.

Проект разработан для запуска в **Google Colab** и демонстрирует полный цикл работы современной RAG-системы.

## 🏗️ Архитектура системы

Система работает по следующему пайплайну:

1. **Приём пользовательского запроса** (вопрос о товаре или услуге)
2. **Поиск информации в интернете** через поисковые системы
3. **Парсинг и очистка веб-страниц**
4. **Разбиение текста на чанки** и создание векторных эмбеддингов
5. **Поиск релевантных фрагментов** с использованием FAISS
6. **Генерация ответа** языковой моделью на основе найденного контекста
7. **Постобработка** и вывод результата

## 🛠️ Технологический стек

### Основные технологии:
- **Python 3.9+** - основной язык разработки
- **Google Colab** - среда выполнения

### Библиотеки для работы с данными:
- **DDGS (DuckDuckGo Search)** - для поиска информации в интернете
- **BeautifulSoup4** - парсинг HTML-страниц
- **Requests** - HTTP-запросы к веб-ресурсам

### NLP и машинное обучение:
- **Sentence Transformers** - создание векторных эмбеддингов текста
- **Transformers (Hugging Face)** - работа с языковыми моделями
- **FAISS (Facebook AI Similarity Search)** - эффективный поиск похожих векторов
- **Qwen/Qwen3-1.7B** - языковая модель для генерации ответов (альтернативно можно использовать другие модели)

### Обработка текста:
- **ftfy** - исправление проблем с кодировкой текста
- **Re (регулярные выражения)** - продвинутая очистка текста

## 🔧 Ключевые функции системы

### 1. Усиленная очистка текста (`text_cleanup`)
- Удаление рекламных блоков, навигационных элементов и технических артефактов
- Фильтрация по релевантности с использованием положительных/отрицательных ключевых слов
- Удаление дублирующихся предложений и нормализация пунктуации

### 2. Веб-поиск и парсинг
- Поиск через DuckDuckGo/Yandex с региональными настройками (ru-ru)
- Имитация браузера для обхода ограничений
- Интеллектуальное извлечение текстового контента

### 3. Векторизация и семантический поиск
- Использование мультиязычной модели `intfloat/multilingual-e5-large`
- Разбиение текста на перекрывающиеся чанки
- Поиск похожих фрагментов с помощью FAISS (метрика L2)

### 4. Генерация ответов
- Контекстуализация запроса на основе найденной информации
- Использование Qwen-модели для генерации
- Постобработка для извлечения чистого ответа


## 🎯 Параметры настройки

Система имеет следующие настраиваемые параметры:
- `max_search_results` (по умолчанию: 15) - количество результатов поиска
- `chunk_size` (по умолчанию: 1500) - размер чанков для разбиения текста
- `overlap` (по умолчанию: 100) - перекрытие между чанками
- `top_k` (по умолчанию: 3) - количество релевантных фрагментов для контекста
- `max_context_size` (по умолчанию: 4500) - максимальный размер контекста для LLM

## 💡 Демонстрируемые навыки

### Технические навыки:
1. **Работа с NLP-библиотеками** - Sentence Transformers, Transformers, FAISS
2. **Веб-скрейпинг и парсинг** - обработка HTML, обход ограничений, очистка данных
3. **Работа с векторными базами данных** - создание и поиск по эмбеддингам
4. **Интеграция языковых моделей** - настройка пайплайнов генерации, работа с токенизацией
5. **Обработка естественного языка** - продвинутая очистка текста, чанкирование, нормализация

### Архитектурные навыки:
1. **Проектирование RAG-систем** - понимание полного цикла от поиска до генерации
2. **Оптимизация производительности** - настройка параметров для баланса скорости и качества
3. **Работа с большими текстами** - стратегии чанкирования и контекстуализации
4. **Интеграция внешних API** - поисковых систем и моделей Hugging Face

### Soft skills:
1. **Решение сложных задач** - обработка "грязных" данных из интернета
2. **Оптимизация качества** - многокритериальная фильтрация релевантного контента
3. **Документирование** - создание читаемого и поддерживаемого кода с комментариями
